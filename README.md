# VR Electrical Laboratory – Kirchhoff's Laws

## Project Overview
An interactive VR electrical laboratory developed using Unity 3D to demonstrate the verification of Kirchhoff's Voltage Law (KVL) and Kirchhoff's Current Law (KCL).

## Experiments
- **KVL:** Series circuit using 100Ω and 200Ω resistors with a 6V DC supply.
- **KCL:** Parallel circuit using 200Ω and 300Ω resistors with a 12V DC supply.

## Features
- Interactive electrical laboratory environment.
- Resistor grabbing and placement.
- KVL and KCL experiment modes.
- Circuit validation and electrical calculations.
- Observation and result verification interface.
- PC simulation and VR interaction support.

## How to Run
1. Clone or download this repository.
2. Open the project through Unity Hub.
3. Use the Unity version specified in ProjectSettings.
4. Open `Assets/Scenes/VR_Content_Sim.unity`.
5. Press Play to run the simulation.

## Technologies
- Unity 3D
- C#
- XR Interaction Toolkit
- OpenXR

## Project Structure
The VR electrical simulation is one scene within the larger Unity project. Its assets, scripts, materials and prefabs are maintained in the shared project folders.
